# 🚀 Quick Start

## Run the Application

### 1. Start the Backend Server (Terminal 1)
```bash
cd server
npm run dev
```
Server runs on: **http://localhost:3000**

### 2. Start the Frontend Client (Terminal 2)
```bash
cd client
npm run dev
```
Client runs on: **http://localhost:3001** (or next available port)
